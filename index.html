Introdução ao JavaScript

O que é JavaScript

É uma linguagem de programação muito utilizada para criar aplicações interativas e sistemas de software.

Ele é responsável por:

  • Responser a cliques
  • Validar formulários
  • Atualizar Conteúdos
  • Buscar dados de API's
  • Controlar o comportamento da aplicação

IMPORTANTE: JavaScript não é Java. Apesar da semelhança nos nome, são linguagens totalmente diferentes, com características e ecossistemas próprios.

Curiosidade: Foi criado em apenas 10 dias.

O que mais da pra fazer com JS?

  • FrontEnd
    • Criar interfaces interativas
    • Menus
    • Validações
    • Filtros
    • Animações
    • Dashboards
    • Aplicações como React, Vue, Angular, Astro e etc.
  • Backend
    • NodeJs
    • Criar API REST
    • Autenticação
    • Processar requisições
    • Integrar com serviços e com banco de dados
  • Mobile/Desktop
    • Criar aplicativos
    • React Native e Electron
